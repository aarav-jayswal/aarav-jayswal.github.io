IEEE 9-Bus Power System Analysis

PSSE Power Flow Analysis Steady-State Operations

Project Details

  • Modeled and solved steady-state power flow for the standard IEEE 9-bus test system using Siemens PSSE, generating visual single-line diagrams from raw network data.
  • Interpreted complex network output reports, analyzing critical metrics including bus voltage profiles, branch MW/Mvar active and reactive power flows, and total system losses.
  • Classified and analyzed the distinct behaviors of slack, PV (generator), and PQ (load) buses, observing how each node type interacts to maintain system-wide energy balance.
  • Conducted exploratory scenario analysis by modifying system loading and adjusting generator dispatch settings (PGEN, PMAX, PMIN) to simulate various theoretical operating conditions.
  • Evaluated the impact of these load and dispatch modifications on voltage stability, successfully identifying infeasible dispatch scenarios and reactive power limit violations indicated by solver constraint flags.

System Response & Constraint Modeling

This simulation-based project provided hands-on experience with industry-standard power flow analysis. By intentionally pushing generator parameters to their maximum limits, I analyzed critical system constraints, such as observing the exact moments a PV bus exhausts its reactive power reserves. Understanding these dynamic network responses, alongside observing how the slack bus automatically compensates for shifting total system losses, reinforced the practical complexities of real-world grid dispatch, load balancing, and voltage control.
